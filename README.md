 Blinkit Sales Dashboard (Power BI)

This project analyzes Blinkit sales data using Power BI to uncover key business insights.

Features
- KPIs: Total Sales, Average Order Value, Customer Retention
- Trend charts for monthly performance
- Category‑wise sales breakdown
- Interactive dashboard design for decision‑making
